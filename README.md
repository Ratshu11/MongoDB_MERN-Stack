# Flight Ticket Booking App

Welcome to the **Flight Ticket Booking App**! ✈️

This **MERN stack** application allows users to search for, book, and manage flight tickets seamlessly. Built with a modern tech stack, this app offers a user-friendly interface and robust features to enhance your travel planning experience.

## Features

- **Search Flights:** Easily find available flights based on your travel criteria.
- **User Authentication:** Secure sign-up and login for personalized experiences.
- **Booking Management:** View, modify, and cancel your bookings with ease.
- **Admin Dashboard:** Manage flights, bookings, and user accounts efficiently.

## Technologies Used

- **MongoDB** for the database
- **Express.js** for the backend server
- **React** for the frontend interface
- **Node.js** for the runtime environment
